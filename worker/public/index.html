NATIVE SSH · ANY TCP CLIENT

Bring your own tool.

Download the local adapter and client SDK into the same folder. Requires Node.js 22.15+.

Native SSH keeps your SSH private key on your machine. Supply the Tailcat address and connect with your usual SSH client.

Custom client protocol · One active connection per Worker isolate.

export TAILCAT_ADDR='tc…'
ssh -o "ProxyCommand=node $PWD/transport.mjs stdio --port 22" user@host

# Or expose a service on a local port:
node transport.mjs forward --listen 127.0.0.1:8080 --port 80
# Then use your existing client:
curl http://127.0.0.1:8080/

The form below runs SSH inside the Worker and requires an SSH key upload. It can hit the current Free plan CPU limit (error 1102); use native SSH above for the tested command path.

Where do I find this?

On the target machine, run:

ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256

Copy the SHA256 fingerprint. It confirms you reached the expected SSH server.

Your credentials pass through this Worker to establish SSH. They are kept in memory for the request; no login, database, or browser storage.
